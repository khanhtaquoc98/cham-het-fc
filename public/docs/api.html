Tài Liệu REST API & cURL Match Highlight

Hệ thống API quản lý 2 góc quay Video YouTube và mốc thời gian ghi chú 2Nike Timeline cho các trận đấu.

🔒 Thông tin Xác Thực (JWT Role): Các API Endpoint dưới đây KHÔNG BẮT BUỘC JWT Token. Bạn có thể tự do gọi cURL từ Telegram Bot, Python, Postman mà không cần đăng nhập.
GET 1. Danh Sách Trận Đấu
/api/history?pageSize=30

Lấy danh sách các trận đấu trong lịch sử bao gồm ngày, giờ, sân thi đấu, đội hình và kết quả.

⚡ Lệnh cURL Request
curl -X GET "{DOMAIN}/api/history?pageSize=30" \
  -H "Accept: application/json"
📥 Response Example (200 OK)

  ]
}
GET 2. Lấy Cấu Hình 2 Video YouTube
/api/youtube-config?match_id={MATCH_ID}

Lấy link YouTube, tiêu đề và số giây trễ offset của 2 góc quay cho trận đấu.

⚡ Lệnh cURL Request
curl -X GET "{DOMAIN}/api/youtube-config?match_id=default_match" \
  -H "Accept: application/json"
📥 Response Example (200 OK)
{
  "configs": [
    {
      "slot": 1,
      "match_id": "default_match",
      "youtube_url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
      "youtube_id": "dQw4w9WgXcQ",
      "title": "Hiệp 1 / Cam 1",
      "start_offset_seconds": 0
    },
    {
      "slot": 2,
      "match_id": "default_match",
      "youtube_url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
      "youtube_id": "dQw4w9WgXcQ",
      "title": "Hiệp 2 / Cam 2",
      "start_offset_seconds": 12
    }
  ]
}
POST 3. Lưu Cấu Hình 2 Video YouTube
/api/youtube-config

Cập nhật link YouTube và căn số giây trễ delay giữa Video 1 và Video 2.

⚡ Lệnh cURL Request
curl -X POST "{DOMAIN}/api/youtube-config" \
  -H "Content-Type: application/json" \
  -d '{
    "match_id": "default_match",
    "configs": [
      { "slot": 1, "youtube_url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ", "title": "Hiệp 1 / Cam 1", "start_offset_seconds": 0 },
      { "slot": 2, "youtube_url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ", "title": "Hiệp 2 / Cam 2", "start_offset_seconds": 12 }
    ]
  }'
📥 Response Example (200 OK)
{
  "success": true,
  "configs": [
    {
      "match_id": "default_match",
      "slot": 1,
      "youtube_url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
      "youtube_id": "dQw4w9WgXcQ",
      "title": "Hiệp 1 / Cam 1",
      "start_offset_seconds": 0
    },
    {
      "match_id": "default_match",
      "slot": 2,
      "youtube_url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
      "youtube_id": "dQw4w9WgXcQ",
      "title": "Hiệp 2 / Cam 2",
      "start_offset_seconds": 12
    }
  ]
}
GET 4. Lấy Danh Sách Highlight 2Nike
/api/youtube-captions?match_id={MATCH_ID}

Lấy tất cả các mốc thời gian ghi chú highlight 2Nike được sắp xếp theo thời gian trận đấu.

⚡ Lệnh cURL Request
curl -X GET "{DOMAIN}/api/youtube-captions?match_id=default_match" \
  -H "Accept: application/json"
📥 Response Example (200 OK)
{
  "captions": [
    {
      "id": "c1f3a2b4-5678-90ab-cdef-1234567890ab",
      "match_id": "default_match",
      "slot": 1,
      "youtube_id": "dQw4w9WgXcQ",
      "timestamp_seconds": 930,
      "timestamp_str": "15:30",
      "caption": "Bàn thắng siêu phẩm sút xa của Tú",
      "created_by": "Admin",
      "created_at": "2026-07-29T10:30:00.000Z"
    }
  ]
}
POST 5. Thêm Mốc Highlight 2Nike Mới

DELETE 6. Xóa 1 Cột Mốc Highlight 2Nike Theo ID
/api/youtube-captions?id={CAPTION_ID}

Xóa một mốc ghi chú highlight 2Nike cụ thể dựa vào ID ghi chú.

⚡ Lệnh cURL Request
curl -X DELETE "{DOMAIN}/api/youtube-captions?id=c1f3a2b4-5678-90ab-cdef-1234567890ab" \
  -H "Accept: application/json"
📥 Response Example (200 OK)
{
  "success": true,
  "id": "c1f3a2b4-5678-90ab-cdef-1234567890ab"
}
DELETE 7. Xóa Sạch Tất Cả Highlight 2Nike Của Trận
/api/youtube-captions?match_id={MATCH_ID}&reset_all=true

Xóa toàn bộ tất cả mốc timeline ghi chú 2Nike của một trận đấu cụ thể.

⚡ Lệnh cURL Request
curl -X DELETE "{DOMAIN}/api/youtube-captions?match_id=default_match&reset_all=true" \
  -H "Accept: application/json"
📥 Response Example (200 OK)
{
  "success": true,
  "count": 5
}
